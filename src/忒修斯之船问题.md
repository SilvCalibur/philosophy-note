# MAIN PART

首先我先更正一下原来的说法，这个问题不是一个“完结了”的问题，而是代表着诸如此类的问题共同作为一个过程存在。
也就是说它们是相对于一个结果来说成为了过程，所以当时我并没有完全遵守黑格尔的说法，因为结果本身就是它过程的全部。
所以它并没有完结，而是成为了“别的东西”，也就是“随后的哲学发展”是诸如此类问题被超越了，或者被克服了的结果。

然后谈回这个问题本身，忒修斯之船之所以令人印象深刻，让人纠结，就是因为意识本身在寻找一个更加普遍的东西。
也就是说想要的回答是：如果它既不是前一艘船，也不是被更换部件甚至全部替换的后一艘船，那么它是什么。

单一物体本身面对着两个问题：
1.物体的特性或属性本身依托于感觉来建立，例如颜色和味道分别被不同的感官所建立，并且也随着不同人的感官而变化，那么它们应该是属于感觉的活动，结果物体本身就又不独立地拥有这些属性了。
2.一个单一的物体想要被认识必须依托于它的属性，例如一个红色的球如果既不是红色也不是球形那它就什么都不是。物体如果想保持同一性它就必须不同于它的各种加起来的属性，但是为了能被认识它又必须是它的属性的综合。

所以物体的属性消解在同一性中，但是对同一性的把握，即意识在认识物体时，又分别与它的属性相关联，反而又建构起来了属性的独立性。可以快速得出结论，物体的特性必须被更普遍的认识所把握，意识把握到了“既是又是”，并且意识也知道了事物的属性就是事物与意识的关联。
忒修斯之船在一开始就是“同时”是被拆解的部件和统一组装的船，“组装起来”并没有影响到单个部件的独立性。也就是说还没等到你问出忒修斯之船这个问题，它最开始被认为是未经变化的同一自身就是不成立的，因为它首先又是由于它的特质和属性而被认识到，意识既然综合了船的全部部件，得出了船的单一概念，所以作为单一概念的船同样必须又是这些分散的部件。
如果把船处理成作为“本质”的船的主体，和“非本质”的可替换的部件，把船的难以变更的主体当成忒修斯之船。那么这个主体，固接的龙骨和桅杆等框架材料，本身又不构成船的概念。为了勉强能成为一艘船，它又必须与非本质的可更换的底层木板、防水材料和钉子等构成一艘最基础能漂浮的船；而为了能航行，剩下一切的甚至是多余的备用繁杂零件又必须回到船上。与非本质对立的本质，如若依赖这个非本质，甚至是最开始依赖与非本质的对立关系而成为本质的，那么它也就不是本质的了，因为它又必须处于一种关系中而不是独立的存在。
